# Radiology playground 

React + Typescript + CornerstoneJS 

cornerstonejs/core: renders images and manages viewports 
cornerstonejs/dicom-image-loader: loads and decodes DICOM images 
dicom-parser: parsers DICOM data 
cornerstonejs/tools: for interactions such as zoom, window/level and measurements 
vite-plugin-commonjs: helps vite process the DICOM parser
